# Medical Study Companion

AI-powered study app for medical students. Upload your lecture slides and turn them into:

- **📝 Spot notes**: high-yield revision notes with comparison tables, buzzwords, mnemonics and common exam traps (printable / save as PDF)
- **🧠 Mind maps**: interactive, zoomable mind maps of the lecture structure
- **🗂 Flashcards**: Anki-style cards with **spaced repetition** (Again / Hard / Good / Easy), a cross-lecture review queue, and **export to Anki**
- **✅ Exam-format quizzes**, in tutor mode (explanation after each question) or timed exam mode:

| Format | Style |
|---|---|
| USMLE Step 1 / Step 2 CK | Long clinical vignettes, single best answer A–E, ~90 s/question |
| PLAB 1 | UK practice, NICE/BNF-based SBA, ~60 s/question |
| AMC CAT MCQ | Australian context, eTG/RACGP-based SBA |
| TUS (Tıpta Uzmanlık Sınavı) | Temel & Klinik Bilimler, 5 şık, in Turkish by default, including "hangisi yanlıştır" items |
| School SBA | Faculty-style mix of recall and short cases |
| EMQ | Theme + 8–12 options + several matching stems |
| Multiple True/False | Stem + 5 independent true/false statements |
| SAQ | Written answer, model answer, and marking points you tick yourself |

- **🎯 Weak topics**: the app tracks your score per topic across quiz attempts, along with flashcards you keep forgetting. It then shows your weakest topics, and one click writes a new quiz focused on them from fresh angles.
- **🩺 Case report writer**: enter a de-identified case and get a draft structured to the **CARE guidelines** (abstract, timeline table, discussion, learning points, consent statement), 3 title options, a to-do list of missing CARE items, and ready-to-run **PubMed searches**. Citations are never invented: the draft has `[REF: …]` placeholders for you to fill with sources you've actually read. Drafts are editable and autosaved, and you can download them as Markdown.

Content is generated by Claude from **your own slides**. Output can be in English or Turkish.

## Two ways to use it

| | 🆓 **Free mode** | ⚡ **One-click mode** |
|---|---|---|
| Cost | Free | A few cents per lecture (Anthropic API) |
| How content is made | The app copies a prompt with your slides → you paste it into [claude.ai](https://claude.ai) (the free plan works) → you paste Claude's reply back | Click a button and it's generated automatically |
| Needs | A free claude.ai account | An Anthropic API key on the server |

Everything else is identical in both modes: quizzes, timed exams, spaced repetition, weak topics, case reports, backup. The app detects the mode by itself, and the header shows 🆓 Free mode or ⚡ One-click mode.

## Your free website (GitHub Pages)

The site is published for free at **https://indho84.github.io/medical-study-companion/** every time `main` changes.

One-time setup: in this repo go to **Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**. That's it. If the first deploy ran before you did this, open the **Actions** tab → *Deploy to GitHub Pages* → **Re-run all jobs**.

## How it works

- Slides (**PDF, PPTX, TXT**) are read **in your browser** (PPTX speaker notes included). In free mode they never leave your device except when you paste the prompt into claude.ai yourself.
- Everything you generate is saved in your browser (IndexedDB). There is no account and no database. Use **Backup / Restore** on the home page to move your library to another device.
- Scanned or image-only slides have no extractable text. Export them from PowerPoint/Keynote with real text, or run OCR first.

## Optional: one-click mode

Run locally (needs [Node.js](https://nodejs.org) 20+ and an API key from <https://console.anthropic.com/>):

```bash
npm install
cp .env.example .env.local      # then paste your key into .env.local
npm run dev
```

Or deploy to [Vercel](https://vercel.com/new) and add the `ANTHROPIC_API_KEY` environment variable there. ⚠️ Anyone with that site's URL can use your key, so turn on Vercel's Deployment Protection. Each generation uses `claude-opus-5-5` and costs roughly a few cents. You can set a monthly spend limit in the Anthropic Console.

## Project structure

```
src/
  app/
    page.tsx               Library + upload
    deck/                  Lecture page (/deck?id=…): notes, mind map, flashcards, quiz, slide text
    review/page.tsx        Review all due flashcards
    case-report/page.tsx   CARE-guideline case report writer
    api/generate/route.ts  Server route for one-click mode (structured JSON output)
  components/              MindMap, QuizRunner, StudySession, panels
  lib/
    examFormats.ts         Exam format definitions + item-writing style guides
    ai.tsx                 Picks one-click vs free mode; the copy/paste dialog
    prompts.ts             Prompts and JSON schemas (shared by both modes)
    postprocess.ts         Parses and validates Claude's JSON
    extract.ts             PDF / PPTX text extraction (browser)
    srs.ts                 SM-2 spaced repetition
    weakTopics.ts          Weak-topic detection from quiz results + flashcard lapses
    db.ts                  IndexedDB storage
```

To add your faculty's own exam format, add an entry to `src/lib/examFormats.ts` with a `guidance` style guide.
